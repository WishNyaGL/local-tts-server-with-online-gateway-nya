# Local TTS + Online Gateway

**Запускает локальный сервер TTS. Параллельно запускается шлюз в котором прописан CURL.**

---

##  Использование

Пока локальный сервер не весь. Может потом добавлю скрипт установки и разворачивания venv Python 3.12.10 с установкой всех пакетов и файлов ттс-ок.
Онлайн работает.
http://127.0.0.1:8890 веб интерфейс настройки.

http://127.0.0.1:8890/v1/audio/speech
http://127.0.0.1:8890/health

---

## ЗАЧЕМ ЭТО НУЖНО

Если в программе захардкожен способ получения голоса только через например openai то у других сервисов есть свои приколы и отличия.
В веб интерфейс просто можно впихнуть CURL api сервиса. А в программу подставить http://127.0.0.1:8890/v1/audio/speech , local-tts и голос (значение из документации) - ВСЁ.
